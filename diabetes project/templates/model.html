ABOUT THE MODEL

Understanding the prediction model.

DiaVista uses a Gaussian Naive Bayes machine learning model to estimate diabetes risk based on selected health parameters.

MACHINE LEARNING ALGORITHM

Gaussian Naive Bayes

Gaussian Naive Bayes is a probabilistic classification algorithm that estimates the probability of an outcome based on the input features.

In this project, the model analyzes several health parameters and estimates the probability associated with the diabetes classification.

Model Accuracy 75.45%
Training Split 80 / 20
Algorithm Gaussian NB

HOW IT WORKS

From input data to prediction.

01

Input Data

The user provides eight health-related parameters required by the model.

02

Probability Calculation

Gaussian Naive Bayes calculates the probability of each possible classification based on the submitted features.

03

Classification

The model selects the classification with the highest estimated probability and returns the prediction to the website.

MODEL FEATURES

Health parameters used by the model.

01 Pregnancies
02 Glucose
03 Blood Pressure
04 Skin Thickness
05 Insulin
06 BMI
07 Diabetes Pedigree Function
08 Age

DATASET

Healthcare Diabetes Dataset

The model was trained using a healthcare diabetes dataset containing patient health measurements and their corresponding diabetes outcome.
